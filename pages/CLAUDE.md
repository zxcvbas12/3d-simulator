# 공통 페이지 지침 (pages/)

> 루트 `../CLAUDE.md`의 공통 규칙 위에 적용된다.

## 여기 들어가는 것
사이트 전체에 걸친 공통 페이지들. 특정 모델·카테고리에 속하지 않는다.
- **소개 (about)** — STRATA가 무엇인지, 누구를 위한 도구인지.
- **학습 구조 (learn)** — 회전 → 분해 → 학습의 3단계 학습 흐름 설명.
- **제작자 의도 (intent)** — 왜 만들었는지, 비전. (제작자 1인칭, 토론토 기반)

## 규칙
- 모든 문구는 `../locales/`의 다국어 키로 둔다. 페이지 본문도 하드코딩하지 말 것.
- 레이아웃·톤은 시안 `homepage-mockup-v2.html`의 공통 페이지 화면을 따른다 (좁은 본문 폭, 모노 eyebrow + 큰 제목 + 차분한 본문).
- 내용 초안은 시안에 한국어·영어·일본어·중국어로 들어가 있으니 출발점으로 쓴다. 실제 문구는 제작자가 다듬는다.
