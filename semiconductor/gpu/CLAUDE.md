# GPU 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md` 규칙 **위에** 적용. 충돌 시 이 파일 우선.
> **품질·연출·인터랙션은 HBM 모델과 동일하게.** (`../hbm/CLAUDE.md`의 "시각 사양 / 환경 / 인터랙션 / 정보 패널 형식"을 그대로 따른다.)

## 이 모델이 표현하는 것
GPU 가속기 **패키지 전체** — 큰 연산 다이(GPU die) 옆에 HBM 스택들이 인터포저를 통해 붙는 2.5D 패키지.
"HBM을 왜 프로세서 바로 옆에 두는가"를 한눈에 보여주는 모델.

## 구조 (아래 → 위, 일부는 평면 배치)
1. **패키지 기판 (Substrate)** — 하단에 BGA 솔더 볼.
2. **실리콘 인터포저 (Interposer)** — 그 위에 GPU 다이와 HBM 스택이 나란히 올라감. 아랫면 C4 범프.
3. **GPU 연산 다이 (Compute Die)** — 중앙의 큰 다이. 마이크로 범프로 인터포저에 연결. 윗면에 연산 블록(SM/코어 어레이) 텍스처.
4. **HBM 스택 × 2~6개** — GPU 다이 양옆에 배치. **HBM 모델(`../hbm`)의 형상을 간략화해 재사용**(적층 블록 + 각인).
5. **(선택) 통합 히트 스프레더 / 리드** — 상단 금속 덮개.

## 분해 방향
수직 적층(HBM 스택 내부)과 **평면 배치**(GPU 다이 옆 HBM)가 섞임.
- 리드(있으면) 위로 → GPU 다이·HBM 스택이 인터포저에서 들어올려지며 분리 → 인터포저 → 기판.
- HBM 스택은 자체적으로 층 분해까지 들어가면 좋다(2단계 분해).

## 색 / 구분
HBM 기준 팔레트 사용하되 **GPU 다이는 구분되는 포인트색**(예: 청록/보라 계열). HBM 스택은 HBM 모델 색 재사용. 금속(범프·볼·리드)은 구리/실버.

## 핵심 학습 포인트 (정보 패널 facts에 반영)
- HBM을 GPU 옆 가까이 두면 데이터 거리가 짧아져 **대역폭 ↑ · 전력 ↓**.
- 인터포저가 두 칩을 수천 배선으로 잇는다(2.5D).
- 큰 연산 다이 + 옆 메모리 = 현대 AI 가속기의 기본 형태.
