# CPU 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md` 규칙 **위에** 적용. 충돌 시 이 파일 우선.
> **품질·연출·인터랙션은 HBM 모델과 동일하게.** (`../hbm/CLAUDE.md`의 "시각 사양 / 환경 / 인터랙션 / 정보 패널 형식"을 그대로 따른다.)

## 이 모델이 표현하는 것
현대 CPU 패키지 — 하나의 큰 다이가 아니라 **여러 칩렛(chiplet)**을 한 패키지에 모은 구조.
"왜 칩을 잘게 나눠 붙이는가(칩렛)"를 보여주는 모델.

## 구조 (아래 → 위, 칩렛은 평면 배치)
1. **패키지 기판 (Substrate)** — 하단에 **LGA 랜드(접점)** 격자(데스크톱) 또는 BGA 볼(모바일). 외부 연결.
2. **컴퓨트 칩렛 (CCD) × 2~여러 개** — 코어가 들어있는 작은 다이들. 기판 위에 나란히. 윗면에 코어 어레이 텍스처.
3. **I/O 다이** — 메모리·입출력·칩렛 간 통신 담당. 컴퓨트 칩렛들과 한 패키지에 함께.
4. **(선택) 브리지/인터포저** — 칩렛 간 고속 연결(EMIB류).
5. **TIM (열전달 물질)** — 다이와 리드 사이 얇은 층.
6. **IHS (통합 히트 스프레더)** — 상단 금속 덮개.

## 분해 방향
**평면 배치 중심**(HBM의 수직 적층과 대비):
- 리드(IHS) 위로 → TIM 층 → 컴퓨트 칩렛·I/O 다이가 옆으로/위로 펼쳐짐 → (브리지) → 기판.

## 색 / 구분
HBM 기준 팔레트. **컴퓨트 칩렛과 I/O 다이는 텍스처로 구분**(코어 그리드 vs I/O 블록). IHS·랜드는 금속(실버), 칩렛은 블루 계열.

## 핵심 학습 포인트 (정보 패널 facts에 반영)
- 칩렛 = 큰 다이를 여러 작은 다이로 분할. **수율↑·비용↓·확장 유연**.
- I/O 다이가 칩렛들과 메모리·외부를 잇는 허브.
- IHS·TIM이 열을 퍼뜨려 식힌다.

## 부품 (클릭 설명: lead / detail / facts)
컴퓨트 칩렛(CCD) · I/O 다이 · 패키지 기판 · LGA 랜드(또는 BGA) · TIM · IHS · (브리지).
