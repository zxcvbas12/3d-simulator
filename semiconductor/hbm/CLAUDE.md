# HBM 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md`의 규칙 **위에** 적용된다. 충돌 시 이 파일이 우선.
> 공통 내용은 반복하지 않는다.

## 이 모델이 표현하는 것
HBM (High Bandwidth Memory) — DRAM 다이를 수직으로 쌓고 TSV로 관통 연결한 적층 메모리.
GPU 옆에 인터포저를 통해 붙는 2.5D 패키징의 핵심 부품. **이 카테고리의 첫 모델이자 기준 구현.**

## 구조 (아래 → 위)
1. **패키지 기판 (Package Substrate)** — 가장 큰 받침. 외부 연결.
2. **실리콘 인터포저 (Interposer)** — HBM과 GPU를 잇는 얇은 실리콘 기판. 2.5D 패키징.
3. **베이스 / 로직 다이 (Base / Logic Die)** — 스택 맨 아래. 메모리 컨트롤러·I/O(PHY).
4. **DRAM 다이 × 여러 층** — 실제 데이터 저장. 기본 8층(실제 세대 8~16층).
5. **TSV (실리콘 관통 전극)** — 층을 수직 관통하는 구리 기둥. 분해 시 **늘어나며 모든 층을 관통**하는 모습이 핵심.
6. **마이크로 범프 (Micro Bump)** — 층 사이를 잇는 작은 솔더 범프. 각 다이 밑면에 격자로.

부품 설명 텍스트(다국어)는 `data.ts`에 둔다. 기존 `hbm-3d.html` 안의 한글 설명을 재활용한다.

## 시각적 포인트
- **포인트 색**: DRAM은 차분한 블루(층마다 명도 미세 변화), TSV·마이크로 범프는 구리/골드.
- 박스마다 얇은 엣지 라인으로 칩 느낌.
- 분해 시 다이들이 벌어지며 그 사이로 TSV 구리 기둥이 드러나는 게 핵심 장면.

## 이 모델 특유의 동작
- 분해 정도(0~1)에 따라 층 간격이 벌어진다. TSV 기둥은 현재 스택 전체 높이에 맞춰 길이를 다시 계산해 항상 모든 층을 관통.
- 마이크로 범프는 각 다이 그룹의 자식으로 두어 다이와 함께 움직이게 한다.
- DRAM 다이는 같은 종류지만 클릭 시 "몇 번째 층"인지 표시.

## 구현 참고
- 동작하는 단일 파일 프로토타입 `hbm-3d.html`이 이미 있다. 형상·색·분해·클릭 정보·카메라 자동 프레이밍이 다 들어있으니,
  맨땅에서 다시 만들지 말고 이 모델의 `model.ts`/`data.ts`로 옮기는 것이 가장 빠르다.

## 향후 확장 (지금은 안 해도 됨)
- 옆에 GPU 다이를 함께 배치해 실제 패키지처럼 보이기
- 단면 절단(cutaway)으로 내부 셀 어레이 표현
- 층 수를 실제 세대(예: 12-high, 16-high)로 선택
