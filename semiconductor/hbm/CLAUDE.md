# HBM 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md`의 규칙 **위에** 적용된다. 충돌 시 이 파일이 우선.
> 공통 내용은 반복하지 않는다. **이 카테고리의 첫 모델이자 다른 모델의 품질 기준(reference).**

## 이 모델이 표현하는 것
HBM (High Bandwidth Memory) — DRAM 다이를 수직으로 쌓고 TSV로 관통 연결한 적층 메모리.
GPU 옆에 인터포저를 통해 붙는 2.5D 패키징의 핵심 부품.

## 구조 (아래 → 위)
1. **패키지 기판 (Substrate)** — 가장 큰 받침. 윗면에 PCB 라우팅, 아랫면에 BGA 솔더 볼.
2. **실리콘 인터포저 (Interposer)** — HBM과 GPU를 잇는 얇은 판. 윗면에 촘촘한 미세 배선, 아랫면에 C4 마이크로 범프.
3. **베이스 / 로직 다이 (Base Die)** — 메모리 컨트롤러·입출력(PHY). 윗면에 큰 기능 블록.
4. **DRAM 다이 × 8층** — 데이터 저장. 윗면에 메모리 뱅크 격자 텍스처. **맨 위 다이엔 "HBM" 레이저 각인.**
5. **TSV (실리콘 관통 전극)** — 층을 수직 관통하는 가는 구리 기둥. 분해 시 스택 높이에 맞춰 늘어나며 모든 층 관통.
6. **마이크로 범프 (Micro Bump)** — 각 다이 밑면의 작은 솔더 볼 격자.
7. **BGA 솔더 볼** — 기판 하단의 외부 연결용 솔더 볼 격자.

## 시각 사양 (현재 구현 기준 — 다른 모델도 이 수준으로)
- **재질**: PBR(MeshStandard) + 절차적 환경맵 반사. 금속(TSV·범프·볼)은 metalness 높게, 다이는 중간.
- **표면 텍스처**: 절차적 canvas 텍스처 — 기판 라우팅, 인터포저 미세 배선, 베이스 기능 블록, DRAM 뱅크 격자, 맨 위 다이 각인. 실제 회로 데이터가 아니라 사실감을 위한 무늬.
- **포인트 색**: DRAM = 차분한 블루(층마다 명도 미세 변화), 금속 = 구리/골드, 솔더 볼 = 실버.
- **엣지 라인**: 모든 박스에 얇은 엣지로 칩 윤곽 강조.

## 환경 / 연출 (전 모델 공통 셸)
- **우주 공간**: 별필드(다층 Points) 배경, 깊은 네이비→블랙 그라데이션. 바닥·그림자 없음.
- **부유감**: 모델이 공중에 떠서 위아래로 천천히 흔들리고(bob), 아주 느린 자동 드리프트. 카메라 기준점은 흔들림과 분리해 부유가 보이게 한다.

## 인터랙션 (전 모델 공통 표준)
- **회전**: 드래그 / 1손가락.
- **확대·축소(줌)**: 스크롤 / 2손가락 핀치 / ＋－ 버튼. 자동 프레이밍 거리에 배율로 얹는다. **분해와 독립.**
- **분해·조립**: 하단 슬라이더 전용. 층이 아래→위 순차 전개(stagger) + 가감속(ease). TSV는 늘어나며 관통.
- **부품 클릭**: 레이캐스트로 선택 → 강조(emissive) + 정보 패널.
- **자동 회전 / 초기화** 버튼(초기화는 회전·줌·분해 모두 리셋).

## 정보 패널 형식 (전 모델 공통)
각 부품 설명은 세 부분으로:
- **lead** — 한 줄 쉬운 요약
- **detail** — 어떻게/왜 중요한지
- **facts[]** — 역할·특징 짧은 항목 3개
DRAM 다이는 클릭 시 "몇 번째 층"인지 표시.

## 구현 참고 (R3F)
- 동작하는 단일 파일 프로토타입 `hbm-3d-space.html`(바닐라 Three.js)에 위 사양이 전부 들어 있다.
  맨땅에서 다시 만들지 말고 **R3F로 이식**한다: 형상은 `model.tsx`(part 묶음을 `shared/r3f`의 `<Viewer>`에 넘김), 설명은 `data.ts`.
- 반복 요소(범프·TSV·BGA)는 drei `<Instances>`로. 분해는 공통 엔진의 "수직" 방향으로.
- 부품 설명은 `data.ts`(lead/detail/facts/출처), 사용자 노출 문구는 모두 `../../locales/` 다국어 키.

## 성능 메모
- 텍스처 512px + 다수 인스턴스(BGA/C4/범프/TSV)로 첫 버전보다 무겁다. 저사양 기기 대비 텍스처 해상도·인스턴스 수를 조절 가능하게 둔다.
