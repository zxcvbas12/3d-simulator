# EV 배터리 팩 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md` 규칙 **위에** 적용. 충돌 시 이 파일 우선.
> **품질·연출·인터랙션은 기존 모델과 동일** — 공통 `<Viewer>` 엔진(`src/shared/r3f/`)을 그대로 쓴다. 모델은 형상(model.tsx)과 설명(data.ts)만 제공.
> **상태: 구현 완료(학습 가능).** 자동차 카테고리 첫 모델.

## 이 모델이 표현하는 것
전기차 배터리 팩 — **셀 → 모듈 → 팩의 3단 계층**과, 그것을 안전·균일하게 유지하는 보조 시스템(냉각·BMS·하우징).
"낮은 전압의 작은 셀을 어떻게 차를 움직이는 큰 에너지로 키우는가"를 보여준다.

## 구조 (아래 → 위, 모듈은 평면 배열)
1. **팩 하우징 (enclosure)** — 차 바닥에 까는 알루미늄 트레이 + 측벽. 픽 `enclosure`.
2. **냉각판 (coldplate)** — 모듈 아래 액냉 판(시안 채널 텍스처). 픽 `coldplate`.
3. **배터리 모듈 (module) × 6** — 3열 × 2행 평면 배열. 각 모듈 = 양옆 엔드플레이트 + 각형 셀 묶음. 픽 `module`(공유 id + `layer` 1~6).
4. **배터리 셀 (cell)** — 모듈 안 각형 셀(인스턴싱). 상단 골드 단자는 장식(픽 제외). 픽 `cell`(모듈 그룹 내 InstancedMesh).
5. **버스바 (busbar)** — 모듈 단자를 잇는 구리 막대(상부 가로 2줄). 픽 `busbar`.
6. **BMS (bms)** — 셀 감시·보호 보드(그린 라우팅 텍스처, 앞쪽). 픽 `bms`.
7. **상단 커버 (lid)** — 팩 위를 덮는 알루미늄 뚜껑. 픽 `lid`.

## 분해 (혼합: 수직 + 평면)
부품별 `explode` 벡터 — 엔진이 `base → base+explode`를 stagger+ease로 보간.
- **커버 ↑ 높이(가장 늦게)** · **버스바 ↑** · **BMS ↑+앞으로** · **모듈은 바깥 방향(±x±z 평면)으로 펼치며 ↑** · **냉각판 ↓ 약간** · **하우징 ↓**.
- order: enclosure 0 → coldplate 0.25 → module 0.45~0.55(순차) → bms 0.7 → busbar 0.8 → lid 1.
- 셀은 모듈 그룹 안에 있어 모듈과 함께 움직인다(모듈이 펼쳐지며 셀 배열이 드러남). **셀 단독 2단계 분해는 향후 보강 후보**.

## 색 / 구분
- 하우징·커버 = 브러시드 알루미늄(실버). 냉각판 = 시안 채널. 셀 = 옅은 스틸(에너지 톤 미세 그린) + 골드 단자. 버스바 = 구리. BMS = 그린 PCB.
- 텍스처는 공용 `@app/shared/r3f/textures` 재사용: `makeBrushedMetalTexture`(알루미늄) · `makeChannelTexture(188)`(냉각) · `makeRoutingTexture(green)`(BMS). **신규 텍스처 없음.**

## 부품 & 치수(spec)
enclosure `≈ 2.0 × 1.5 m` · coldplate `liquid (glycol/water)` · module `≈ 12–24 cells` · cell `prismatic Li-ion ≈ 3.7 V` · busbar `Cu/Al 고전류` · bms `V/T/I + balancing` · lid `sealed Ni/Al`. (단순화 — 실제 셀 수·치수는 차종마다 다름.)

## 핵심 학습 포인트 (facts 반영됨)
- 셀(≈3.7 V)을 **직렬로 길게 이어** 수백 V → 차를 움직임. 버스바가 대전류를 나름.
- 팩 > 모듈 > 셀 **3단 계층** — 조립·교체·관리가 쉬워짐.
- 냉각판이 온도를, BMS가 전압·균형을 지켜 **안전·수명** 확보.
