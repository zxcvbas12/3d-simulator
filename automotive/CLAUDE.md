# 자동차 (Automotive) 카테고리 지침

> 루트 `../CLAUDE.md`의 공통 규칙 **위에** 적용된다. 충돌 시 이 파일이 우선. 공통 내용은 반복하지 않는다.
> 개별 모델 지침은 각 모델 폴더의 `CLAUDE.md`에 둔다. 품질 기준은 반도체 3종(루트 "모델 품질 체크리스트").

## 이 카테고리의 범위
자동차의 **동력계(powertrain)** 를 중심으로 다룬다 — 에너지를 저장하고(배터리), 변환하고(모터·엔진), 바퀴로 보내는 구조.

## 이 카테고리 공통 사항
- **분해 방향**: **혼합**(수직 + 평면). 부품이 한 하우징 안에 중첩·배열되는 경우가 많아, 커버·상부는 수직으로 들어올리고 내부 모듈·부품은 평면으로 펼친다. (반도체의 순수 적층, 우주의 동심 껍질과 구분.)
- **포인트 색**: 에너지·전동 톤으로 **시안~틸 그린**을 보조 강조에 쓴다(냉각·셀). 금속은 루트 팔레트(구리·실버·골드) 유지. 과채도 금지.
- **썸네일 모티프**: `cells`(반복 셀 격자) — 카탈로그 `thumb`.
- **공통 용어**: 셀(cell)·모듈(module)·팩(pack)·BMS·버스바(busbar)·고정자/회전자(stator/rotor) 등. 다국어 표기는 각 모델 `data.ts`와 `../locales/`에서 통일.

## 이 카테고리의 모델 목록 (3종 완성)
- **ev-battery** — EV 배터리 팩 · 상태: 학습 가능(셀→모듈→팩 3단 계층, 혼합 분해)
- **drive-motor** — 구동 모터 · 상태: 학습 가능(PMSM, 사이트 첫 축방향 분해 — 배터리와 "전기 동력계" 한 쌍)
- **combustion-engine** — 내연기관 엔진 · 상태: 학습 가능(4행정, 정비 순서 수직 분해, 크랭크 위상 시각화 — 전기 동력계와의 대비)

추천 학습 순서(카탈로그 `guide` 등록됨): **EV 배터리 → 구동 모터 → 내연기관** — 저장 → 구동 → 대비.

## 메모
- 공통 동작(회전/줌/분해/정보패널/셸)은 `../src/shared/`를 그대로 재사용한다.
- 모델이 2종 이상으로 늘고 추천 순서가 생기면 카탈로그 `CategoryEntry.guide`에 추가한다(공통 페이지에는 두지 않는다).
- 모든 사용자 노출 텍스트는 `../locales/`의 다국어 키 또는 모델 `data.ts`.
