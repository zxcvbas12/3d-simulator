> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md` 규칙 **위에** 적용. 충돌 시 이 파일 우선.
> **품질·연출·인터랙션은 기존 모델과 동일** — 공통 `<Viewer>` 엔진(`src/shared/r3f/`)을 그대로 쓴다. 모델은 형상(model.tsx)과 설명(data.ts)만 제공.
> **상태: 구현 완료(학습 가능).** 자동차 카테고리 세 번째(마지막 예정) 모델 — 전기 동력계와의 대비.

## 이 모델이 표현하는 것
직렬 4기통 DOHC 가솔린 엔진 — **4행정(흡입·압축·폭발·배기) 사이클**.
"연료의 폭발(직선 운동)이 어떻게 회전이 되는가"를 보여준다. EV 배터리·구동 모터와 대비되는 모델.

## 구조 (위 → 아래) — 8부품
1. **밸브 커버 (valvecover)** — 브러시드 알루미늄 덮개 + 오일 캡(장식).
2. **캠샤프트 (camshaft)** — DOHC 2축(z=±0.45) + 타원 캠 로브 + 타이밍 스프로킷(장식). 한 부품 그룹.
3. **실린더 헤드 (head)** — 알루미늄 블록 + 점화플러그 4개(골드, 장식) + 연소실 자국(아랫면).
4. **실린더 블록 (block)** — 주철 톤 본체 + 보어 개구 4개(장식). 분해 시 제자리(기준점).
5. **피스톤 (piston) × 4** — 크라운 + 링 그루브 2줄. 공유 id + `layer` 1~4. **크랭크 위상(1·4 상사점, 2·3 하사점)대로 높이가 다름** — 점화순서 1-3-4-2의 시각화.
6. **커넥팅 로드 (conrod) × 4** — I빔 + 대단부 토러스 + 소단부 핀. 위상에 따라 길이 가변 빌더 `buildConrod(len)`. 공유 id + `layer`.
7. **크랭크샤프트 (crankshaft)** — 메인 저널 + 위상 오프셋 핀 4개 + 웹/카운터웨이트 + 플라이휠.
8. **오일팬 (oilpan)** — 강판 트레이 + 드레인 플러그(골드, 장식).
- 조립 상태에서 피스톤·로드·크랭크는 블록·팬 안에 숨는다(실제 외형). 플라이휠만 +x 끝에 노출.

## 분해 (정비 순서 수직 분해)
실제 엔진 티어다운 순서: **밸브커버 ↑ (order 0) → 캠샤프트 ↑ (0.15) → 헤드 ↑ (0.3) → 피스톤 ↑ 보어에서 인출(0.45~, 순차) → 커넥팅 로드 ↑ (0.58~) → 블록 제자리(0.5, explode 0) → 크랭크샤프트 ↓ (0.8) → 오일팬 ↓ (1)**.
- 분해 후 피스톤 4개의 높이 차(위상)가 그대로 유지된다 — 학습 포인트.
- 캠샤프트(z=±0.45)와 피스톤(z=0)은 z가 달라 3D상 겹치지 않는다.

## 색 / 구분
- 밸브커버 = 브러시드 알루미늄(`makeBrushedMetalTexture` — **신규 텍스처 0**), 헤드 = 밝은 주조 알루미늄, 블록 = 어두운 주철 톤, 피스톤·크랭크 = 밝은 강철, 로드 = 중간 강철, 오일팬 = 진한 강판. 포인트 골드 = 점화플러그·드레인 플러그.

## 부품 & 치수(spec)
valvecover `주조 Al/Mg` · camshaft `DOHC ×2 · 크랭크 ½속` · head `주조 Al · 연소실` · block `직렬4 · ≈2.0L` · piston `단조 Al · 4행정` · conrod `단조강 I빔` · crankshaft `단조강 → 플라이휠` · oilpan `오일 ≈4–5L`. (대표값.)

## 핵심 학습 포인트 (facts 반영됨)
- **4행정**: 흡입→압축→폭발→배기 — 힘이 나오는 건 폭발 행정뿐, 4기통이 1-3-4-2로 번갈아 맡는다.
- 피스톤(직선) → 커넥팅 로드 → 크랭크샤프트(회전) — 자전거 페달과 같은 원리.
- 캠샤프트는 크랭크의 절반 속도(4행정 = 크랭크 2회전당 밸브 1회 개폐).
- 전기 동력계와의 대비: 같은 문제(에너지→바퀴 회전)의 다른 해법. 열효율 ≈30–40% vs 모터 ≈90%+.
