# 구동 모터 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md` 규칙 **위에** 적용. 충돌 시 이 파일 우선.
> **품질·연출·인터랙션은 기존 모델과 동일** — 공통 `<Viewer>` 엔진(`src/shared/r3f/`)을 그대로 쓴다. 모델은 형상(model.tsx)과 설명(data.ts)만 제공.
> **상태: 구현 완료(학습 가능).** EV 배터리와 묶이는 "전기 동력계" 한 쌍의 두 번째 모델.

## 이 모델이 표현하는 것
EV의 표준 구동 모터 — **영구자석 동기 모터(PMSM, IPM)**.
"배터리의 전기가 어떻게 바퀴를 돌리는 회전력이 되는가"를 보여준다. 학습 흐름: EV 배터리(저장) → 구동 모터(구동).

## 구조 (축 = x방향으로 누운 원통, 바깥 → 안)
1. **하우징 (housing)** — 열린 원통 셸(브러시드 알루미늄, DoubleSide) + 냉각 핀 토러스 ×7(장식, 픽은 부모 귀속). 픽 `housing`.
2. **엔드캡 (endcap) × 2** — 양끝 원판 + 중앙 허브 + 볼트 8개(인스턴싱, 장식). 공유 id + `layer` 1/2. 픽 `endcap`.
3. **베어링 (bearing) × 2** — 외륜 토러스 + 강구 10개(인스턴싱, 장식). 공유 id + `layer` 1/2. 픽 `bearing`.
4. **고정자 (stator)** — Lathe 단면 회전 링(내경 0.95 / 외경 1.5) + 적층 라인 토러스(장식). 픽 `stator`.
5. **권선 (winding)** — 양끝 구리 엔드와인딩 토러스 + 슬롯 구리 막대 12개(인스턴싱, `partId` 부여). 픽 `winding`.
6. **회전자 (rotor)** — 강철 원통(r 0.88) + 표면 영구자석 슬래브 8개(인스턴싱, 픽은 rotor 귀속) + 양끝 링. 픽 `rotor`.
7. **샤프트 (shaft)** — 중심 출력축 + 스플라인 단(+x 끝). 픽 `shaft`.
- 조립 상태에서 회전자(r .88)가 고정자 내경(.95) 안에 들어가고 샤프트 끝만 엔드캡 밖으로 나온다(실제 외형).

## 분해 (사이트 첫 "축방향(axial)" 분해)
실제 모터 분해 순서를 따른다 — 부품별 `explode` 벡터 + stagger:
- **하우징 ↑ (order 0, 가장 먼저)** — 셸이 들리며 내부 공개.
- **엔드캡 ±x (0.2)** → **베어링 ±x (0.35)** → **회전자 +x 슬라이드 (0.5)** → **샤프트 +x 더 멀리 (0.62)** → **권선 ↑ (0.78)** → **고정자 ↓ (0.9)**.
- 샤프트가 분해 후에도 엔드캡 중심을 관통해 보이는 건 의도(실제로 보어를 지나간다).

## 색 / 구분
- 하우징·엔드캡·베어링·샤프트 = 실버/알루미늄 계열, 권선 = **구리**(분해 시 시각적 포인트), 고정자 = 어두운 적층 강판, 회전자 = 진한 강철 + 차콜 자석.
- 텍스처: `makeBrushedMetalTexture`(하우징)만 사용 — **신규 텍스처 0**. 원통류는 PBR 재질 + 엣지/장식 링으로 표현.

## 부품 & 치수(spec)
housing `Al · 액랭/유랭` · endcap `주조 Al · 베어링 홀더` · stator `적층 강판 링` · winding `Cu · 3상 · 헤어핀` · rotor `영구자석 · ≤ ~16,000 rpm` · shaft `강철 → 감속기` · bearing `볼 베어링 ×2`. (대표값 — 차종마다 다름.)

## 핵심 학습 포인트 (facts 반영됨)
- 고정자 권선의 3상 전류 → **회전 자기장**, 영구자석 회전자가 그것을 따라 돈다(= 동기 모터).
- 적층 강판(와전류 손실↓), 헤어핀 권선(효율↑), IPM 자석 배치(고속 안정) — EV 모터의 표준 설계.
- 1만+ rpm 회전은 감속기(≈9:1)를 거쳐 토크로 바뀌어 바퀴로 나간다.
