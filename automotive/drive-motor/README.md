# 구동 모터 — 모델

> **핵심 질문: 배터리의 전기가 어떻게 바퀴를 돌리는 힘이 되는가?**
> EV의 표준인 **영구자석 동기 모터(PMSM)**입니다. 고정자 권선의 3상 전류가 회전하는 자기장을 만들고, 영구자석이 박힌 회전자가 그 자기장을 따라 돕니다. [EV 배터리 팩](../ev-battery/)과 이어 보면 "저장 → 구동"의 전기 동력계가 완성됩니다.

## 구조 (축방향으로 누운 원통, 바깥 → 안)

| 부품 id | 부품 | 표현 |
|---|---|---|
| `housing` | 모터 하우징 | 냉각 핀 달린 알루미늄 원통 셸 |
| `endcap` | 엔드캡 ×2 | 양끝 원판 + 허브 + 볼트 (베어링 홀더) |
| `bearing` | 베어링 ×2 | 외륜 + 강구 10개 (인스턴싱) |
| `stator` | 고정자 | 적층 강판 링 (움직이지 않음) |
| `winding` | 권선 | 구리 엔드와인딩 + 슬롯 막대 12개 |
| `rotor` | 회전자 | 강철 원통 + 내장(IPM) V자 자석 16개 — 끝면에 V 단면 노출 |
| `shaft` | 샤프트(출력축) | 중심 축 + 스플라인 단 |

## 동작 — 사이트 첫 축방향(axial) 분해

실제 모터 분해 순서를 따릅니다: **하우징이 위로 열리고** → 엔드캡·베어링이 축을 따라 양옆으로 빠지고 → **회전자·샤프트가 축 방향으로 슬라이드해 나오고** → 구리 권선과 고정자가 분리됩니다. 엔드캡·베어링 클릭 시 "n번째" 표시(`layer`).

- **구동 연출**: 자동 회전을 켜면 회전자·샤프트가 실제로 돕니다 — 분해 상태에서도 돌아 "어디가 회전부인지" 보여줍니다.
- **단면(cutaway) 옵션**: 절단면으로 고정자 슬롯·권선 단면과 회전자 내부의 **IPM V자 자석 배치**를 봅니다. 회전 연출과 조합하면 절단면이 돌아가며 보입니다.

## 주요 사양 (정보 패널·카탈로그)

PMSM (IPM) · ≈ 150–300 kW · 최고 ≈ 16,000 rpm · 3상 AC(인버터 구동) · NdFeB 희토류 자석 · 워터재킷/오일 냉각 · 샤프트 → 감속기 ≈ 9:1

## 학습 포인트

1. 고정자의 3상 전류가 **회전 자기장**을 만들고, 회전자의 영구자석이 그것을 따라 돈다 — "동기" 모터라는 이름의 이유.
2. 적층 강판(와전류 손실↓) · 헤어핀 권선(구리 충전율↑) · 자석 내장 IPM(고속 안정) — 현대 EV 모터의 3대 설계.
3. 1만 rpm 이상의 고속 회전은 감속기를 거쳐 **속도를 토크로 바꿔** 바퀴에 전달된다.

## 구현 메모

- 신규 절차 텍스처 없이 구현 — 하우징만 `makeBrushedMetalTexture`, 나머지는 PBR 재질 + 토러스/인스턴싱(핀·볼트·강구·자석·권선 막대).
- 교육용 단순화: 자석은 실제로는 회전자 내부에 V자로 묻히지만(IPM) 여기서는 표면 슬래브로 보여줍니다. 권선도 실제 수백 가닥을 12개 막대로 추상화.
