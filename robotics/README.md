# 로보틱스 (Robotics) — 카테고리

로봇을 **움직이고 감지하게 하는** 핵심 부품을 3D 분해도로 다루는 카테고리입니다 — 관절 하나(액추에이터) → 관절의 조합(손) → 눈(라이다).

## 모델 목록

| 모델 | 상태 | 핵심 질문 | 분해 방식 |
|---|---|---|---|
| [`actuator/`](actuator/) 로봇 액추에이터 | ✅ 학습 가능 | 모터의 빠른 회전이 **어떻게 정밀한 관절 움직임이 되는가** | 축방향 + 동심 |
| `humanoid-hand/` 휴머노이드 손 | ⏳ 준비 중 | 관절들이 모이면 **어떻게 손이 되는가** | 다관절 예정 |
| `lidar/` 라이다 | ⏳ 준비 중 | 로봇은 **어떻게 거리를 보는가** | 동심 예정 |

## 이 카테고리의 공통 시각 언어

- **분해 방향**: 축방향 + 동심 — 원통 모듈의 하우징을 들어올리고 내부를 축을 따라 일렬로 펼친다.
- **색**: 금속 기계 톤(실버·스틸) + 구리·골드 기능 강조(권선·베어링·캠).
- **공통 용어**: 액추에이터 · 하모닉 드라이브 · 엔코더 · 토크 · 자유도(DOF) · 중공축.

## 폴더 구성

각 모델 폴더는 `model.tsx`(형상) + `data.ts`(부품 설명 4개 언어) + `README.md`(사람용) + `CLAUDE.md`(AI 지침)로 구성됩니다. 회전·줌·분해·선택·정보 패널은 [`src/shared/r3f/`](../src/shared/r3f/)의 공통 엔진이 처리합니다.

## 정확성에 대해

모델은 대표적인 구조를 따르되 **교육 목적으로 단순화**되어 있습니다(치형 수·비례 등은 보기 좋게 조정). 부품 설명의 치수(`spec`)는 대표적인 수치 범위를 표기합니다.
