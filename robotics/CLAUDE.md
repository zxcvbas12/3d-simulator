# 로보틱스 (Robotics) 카테고리 지침

> 루트 `../CLAUDE.md`의 공통 규칙 **위에** 적용된다. 충돌 시 이 파일이 우선. 공통 내용은 반복하지 않는다.
> 개별 모델 지침은 각 모델 폴더의 `CLAUDE.md`에 둔다.

## 이 카테고리의 범위
로보틱스 (Robotics) 분야의 제품들을 분해도로 다룬다.

## 이 카테고리 공통 사항 (모델 추가 시 채울 것)
- [ ] **분해 방향**: 이 분야 제품이 주로 수직 적층인지, 평면 배치인지, 동심(껍질) 구조인지 정하고 기본 분해 방식을 메모.
- [ ] **포인트 색**: 카테고리를 구분할 강조색 (루트의 블루·구리·골드 팔레트 안에서).
- [ ] **썸네일 모티프**: 사이드바/카드에서 이 분야를 상징할 형태.
- [ ] **공통 용어**: 이 분야에서 반복되는 부품·개념의 다국어 표기 통일.

## 이 카테고리의 모델 목록
- [ ] 모델 폴더를 추가할 때마다 여기에 한 줄씩 기록 (이름 / 상태: 준비 중·학습 가능).

## 메모
- 공통 동작(회전/줌/분해/정보패널/사이드바)은 `../shared/`를 그대로 재사용한다.
- 이 분야 특유의 동작이 필요하면 `shared/`를 일반화하되 기존 모델을 깨지 않는다.
- 모든 사용자 노출 텍스트는 `../locales/`의 다국어 키로 둔다.
