# 로보틱스 (Robotics) 카테고리 지침

> 루트 `../CLAUDE.md`의 공통 규칙 **위에** 적용된다. 충돌 시 이 파일이 우선. 공통 내용은 반복하지 않는다.
> 개별 모델 지침은 각 모델 폴더의 `CLAUDE.md`에 둔다. 품질 기준은 반도체 3종(루트 "모델 품질 체크리스트").

## 이 카테고리의 범위
로봇을 **움직이고(액추에이터·손) 감지하게(라이다) 하는** 핵심 부품을 다룬다 — 관절 하나 → 관절의 조합 → 눈의 흐름.

## 이 카테고리 공통 사항
- **분해 방향**: **축방향 + 동심** 중심. 관절·센서류는 원통 모듈 안에 동심으로 쌓이므로, 하우징을 들어올리고 내부를 축을 따라 일렬로 펼친다(구동 모터 패턴 재사용).
- **포인트 색**: 금속 기계 톤(실버·스틸) + **구리·골드를 기능 강조**(권선·베어링·타원 캠)에. 과채도 금지.
- **썸네일 모티프**: `joint`(두 세그먼트 + 피벗) — 카탈로그 `thumb`.
- **공통 용어**: 액추에이터(actuator) · 하모닉 드라이브/스트레인 웨이브 기어 · 엔코더 · 토크 · 자유도(DOF) · 중공축(hollow bore). 다국어 표기는 각 모델 `data.ts`에서 통일.
- **구동 연출**: 관절·기어류는 자동 회전 시 실제로 돌리는 연출이 잘 어울린다(`update` 훅 dt·autoRotate) — 입력/출력 속도 차로 감속을 시각화.

## 이 카테고리의 모델 목록
- **actuator** — 로봇 액추에이터 · 상태: 학습 가능(일체형 관절 모듈, 하모닉 드라이브 동심 3겹, 축방향 분해 + 감속 연출 + 단면)
- **humanoid-hand** — 휴머노이드 손 · 상태: 준비 중 (다음 후보 — 액추에이터의 조합)
- **lidar** — 라이다 · 상태: 준비 중 (감지 — 회전 미러·송수신부)

모델이 2종 이상 되면 추천 학습 순서를 카탈로그 `CategoryEntry.guide`에 추가한다(예정: 액추에이터 → 휴머노이드 손 → 라이다 — 관절 → 조합 → 감지).

## 메모
- 공통 동작(회전/줌/분해/정보패널/셸)은 `../src/shared/`를 그대로 재사용한다.
- 모든 사용자 노출 텍스트는 `../locales/`의 다국어 키 또는 모델 `data.ts`.
