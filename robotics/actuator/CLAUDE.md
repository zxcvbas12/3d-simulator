# 로봇 액추에이터 모델 지침

> 루트 `../../CLAUDE.md` + 카테고리 `../CLAUDE.md` 규칙 **위에** 적용. 충돌 시 이 파일 우선.
> **품질·연출·인터랙션은 기존 모델과 동일** — 공통 `<Viewer>` 엔진(`src/shared/r3f/`)을 그대로 쓴다. 모델은 형상(model.tsx)과 설명(data.ts)만 제공.
> **상태: 구현 완료(학습 가능).** 로보틱스 카테고리 첫 모델.

## 이 모델이 표현하는 것
협동로봇·휴머노이드 관절의 **일체형 액추에이터** — 모터·감속기·센서·베어링이 한 통에 든 관절 모듈.
"모터의 빠른 회전이 어떻게 크고 정밀한 관절 토크가 되는가"를 보여준다. 주인공은 **하모닉 드라이브(동심 3겹)**.

## 구조 (축 = x방향 원통, 입력 -x → 출력 +x) — 8부품
1. **하우징 (housing)** — 열린 원통 셸(브러시드 Al, DoubleSide) + 케이블 그로밋(장식).
2. **엔코더 (encoder)** — 슬릿 디스크 + 눈금 36개(인스턴싱, 장식) + 리더 PCB 링. x=-1.1.
3. **프레임리스 BLDC 모터 (motor)** — 고정자 링 + 구리 권선 띠 18개 + 자석 로터 링, 한 부품. x=-0.35.
4. **웨이브 제너레이터 (wavegen)** — 타원 캠(scale y1.18/z0.85) + 골드 타원 베어링 링 + 입력축. x=0.55.
5. **플렉스플라인 (flexspline)** — Lathe 얇은 컵(바닥 +x, 림이 -x로 웨이브 제너레이터를 감쌈) + 림 바깥 치형 24개. x=0.55.
6. **서큘러 스플라인 (circspline)** — 고정 링 기어 + 안쪽 치형 26개. x=0.2 (플렉스 림 치형 구간을 감쌈).
7. **크로스롤러 베어링 (crossroller)** — 외륜 링 + 롤러 16개 **90° 교차 배치**(인스턴싱 extraRot). x=1.25.
8. **출력 플랜지 (flange)** — 디스크 + 볼트 8개 + 중공축 구멍(짙은 디스크). x=1.55.
- 치형·롤러·볼트·눈금은 전부 `ringInstances()` 헬퍼(원주 배치 인스턴싱) — 장식, 픽은 부모 귀속.

## 분해 (축방향: 하우징 ↑ → 엔코더 -x → 하모닉 3겹·베어링·플랜지 +x 일렬)
- housing ↑(order 0) → encoder -x(0.2) → motor -x(0.35) → wavegen +x(0.5) → flexspline +x(0.62) → circspline +x(0.74) → crossroller +x(0.85) → flange +x(1).
- 동심 3겹(캠 안 / 컵 중간 / 링 바깥)이 분해되면 +x로 나란히 — 하모닉 드라이브 구성을 한눈에.

## 구동 연출 + 옵션
- **감속 시각화**: 자동 회전 시 웨이브 제너레이터(입력)는 빠르게(spinIn), 플렉스플라인·플랜지(출력)는 **느리게 역방향**(-spinIn/12). 실제 감속비 ≈100:1은 출력이 안 보일 정도라 시연은 12:1로 과장 — data.ts에 실제 수치 명시.
- **단면(cutaway)**: 공용 헬퍼 — 조립 상태에서 동심 구조(모터 링·권선·하모닉·베어링) 단면 노출.

## 색 / 구분
하우징·플랜지 = 브러시드/주조 Al, 모터 고정자·서큘러 스플라인 = 어두운 강판, 로터·엔코더 = 차콜, 권선 = **구리**, 웨이브 제너레이터 베어링 링 = **골드**(타원 강조), 컵·캠·롤러 = 밝은 강철. 신규 텍스처 0(브러시드 메탈만 재사용).

## 부품 & 치수(spec)
housing `Al 관절 모듈` · encoder `absolute 17–20bit` · motor `frameless BLDC` · wavegen `타원 캠·입력` · flexspline `유연 강철 컵·출력` · circspline `고정 링 기어` · crossroller `90° 교차 롤러` · flange `볼트 원 → 다음 링크`. (대표값.)

## 핵심 학습 포인트 (facts 반영됨)
- 하모닉 드라이브: **이 2개 차이**의 유연한 컵 → 감속비 ≈100:1, 부품 3개, 백래시 ≈0.
- 모터는 빠르고 약함 → 감속기가 속도를 토크로 바꿈. 출력은 입력의 **역방향**.
- 일체형 관절 모듈 6~7개 연결 = 로봇 팔(자유도 6~7). 케이블은 중공축 통과.
